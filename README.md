# AI Word 模板填充

> 用自然语言驱动，把 Excel / JSON 中的结构化数据批量填入 Word 模板，自动生成文档。
> 智能体开发实战 · 04 题

---

##  快速开始

**本项目以压缩包形式发布。请下载 `word-template-filler.zip`，解压后阅读其中的 `README.md` 获取完整文档。**

```bash
# 1. 下载并解压
unzip word-template-filler.zip
cd word-template-filler

# 2. 详细文档在这里
cat README.md          # Linux / macOS
type README.md         # Windows
```

压缩包内已包含全部内容：**可执行代码、示例模板与数据、自动化测试、智能体 Skill 声明**
 **Windows 用户请注意**
> 请使用 [7-Zip](https://www.7-zip.org/)（免费开源）解压，右键 → 7-Zip → 提取到当前位置。
> Windows 自带解压工具处理中文文件名时会出现乱码，导致找不到模板文件。
> 若已产生乱码文件名，进入项目目录执行 `python skills/scripts/make_samples.py` 可重新生成示例文件。
**更多细节请下载 `word-template-filler.zip` 解压后查看 `README.md`。**
